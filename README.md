# LPI Linux Essentials — Apuntes de Estudio

- Apuntes de estudio desarrollados como complemento práctico/técnico al temario de **Linux Professional Institute (LPI) Linux Essentials**, aplicado sobre un sistema **Arch Linux** con enfoque en filosofía KISS, Btrfs y herramientas de línea de comandos.
- Proyecto diseñado para organizar el aprendizaje de forma progresiva, desde los fundamentos filosóficos del software libre hasta el mantenimiento avanzado del sistema.

## Contenido

| Fase | Temas | Archivos |
|------|-------|----------|
| **Fase 1:** Filosofía Open Source, KISS y Distribuciones | Evolución de Linux, filosofía KISS, licencias (GPL, BSD, CC), Arch vs Ubuntu | Teoría, Cuestionario |
| **Fase 2:** Instalación de Arch con Btrfs y Fundamentos de la Shell | Particionado, pacstrap, subvolúmenes Btrfs, sintaxis de comandos, variables de entorno | Teoría, Comandos, Reto |
| **Fase 3:** Documentación y Gestión del Sistema de Archivos | man, info, locate, find, estructura jerárquica del filesystem | Teoría, Comandos, Reto |
| **Fase 4:** Flujos de Datos y Scripting en Bash | Compresión (tar, gzip), pipes, filtros (grep, cut), scripting con vi/nano | Teoría, Comandos, Reto |
| **Fase 5:** Hardware, Procesos, Logs y Redes | /dev, ps, top, kill, journalctl, systemctl, NetworkManager | Teoría, Comandos, Reto |
| **Fase 6:** Seguridad y Permisos Especiales | usuarios, grupos, sudoers, enlaces, Sticky Bit | Teoría, Comandos, Reto |
| **Fase 7:** Mantenimiento y Resiliencia con Snapshots | pacman, AUR, Snapper, GRUB-Btrfs, chroot | Teoría, Comandos, Reto |
